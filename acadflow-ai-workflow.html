🐛 Bugs Fixed Today

B1 · Fatal parse error

Orphaned duplicate code in AcademicRulePack.php broke RuleEngine autoload. Fixed via php -l + surgical removal.

B2 · Cache invalidation no-op

AiCache::forgetScope() never tagged keys. put() now tracks scopes; invalidated on settings change & re-analysis.

B7 · PDF parser missing

smalot/pdfparser not in composer.json → all PDFs fell back to garbage text. Added dependency + improved fallback.

B3/B4 · Cost limits broken

Limits tied to logging toggle; provider costs never tracked. Decoupled + added per-request accounting.

UUID missing on create

SubmissionTask + 7 models used uuid as route key but never generated it. Added booted() hooks platform-wide.

B5 · Hybrid mode never escalated

Rule engine treated as sufficient by default. Added ai_hybrid_escalate_when_clean toggle + settings UI.

B10 · Runtime settings ignored

AiCache + providers read config() not SettingService. DB toggles now take effect immediately.

B11 · Analytics mislabeled

Provider-fallback responses stamped rule_engine. Now uses rule_engine_fallback for accurate source attribution.

Route name mismatch

lecturer.submission.review didn't exist. Fixed 3 files to use submissions.review.

Collection::total() error

notifications/index.blade.php called total() on an Eloquent Collection. Fixed to count().

format() on string

Notification + SubmissionVersion had $timestamps=false without datetime casts. Added casts + null-safe views.

Stray dd() debug

Leftover dd($currentVersion) crashed SubmissionController. Removed.
