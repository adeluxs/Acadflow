AcadSyntra Chapter Two literature insertion validation — 2026-09-16

- Literature buttons dispatched acadflow:editor-insert to the textarea.
- The fallback editor listened for the event, but the normal Quill editor did not.
- Therefore the UI could report "Inserted" while the visible Quill editor remained unchanged.

Implemented:
- Shared editor registry for Quill and fallback editors.
- Single centralized acadflow:editor-insert listener.
- window.AcadFlowRichEditor.insert(target, text) API.
- Pre-initialization pending insertion queue for dynamic editor loading.
- Immediate hidden-textarea synchronization after insertion, preserving Save version behavior.
- Duplicate fallback insertion listener removed.
